Una calculadora desarrollada con JAva y Maven.

Esta calculadora te permite realizar las siguientes operaciones:

- Sumar dos numeros.
- Restar dos numeros
- Multiplicar dos numeros
- Dividir dos numeros, y en caso de que de cero, muestre error

Se requiere lo siguiente para que funcione:
Java 21
Apache Maven

La estructura del proyecto es la siguiente:

calculadora-java/
├── pom.xml
├── .gitignore
├── README.md
└── src/
    └── main/
        ├── java/
        │   └── es/daw/calculadora/
        │       ├── Main.java
        │       └── Calculadora.java
        └── resources/
